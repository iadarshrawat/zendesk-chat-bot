Comfort Zone RAG package

This package is a complete brand snapshot for the backend knowledge ingestion command. It contains image-free searchable manuals, the verified product catalog, and preserved policy documents.

Validate first

npm run ingest -- --source "./Comfort_Zone_RAG_Updated.zip" --brand-key comfort-zone --validate-only

Publish only after validation passes

npm run ingest -- --source "./Comfort_Zone_RAG_Updated.zip" --brand-key comfort-zone

Important

  • Validation does not upload vectors or publish a snapshot.
  • Generated manuals contain text only; original graphics were removed.
  • Retain the original PDFs for wiring, assembly, and spatial diagrams.
  • OCR_REVIEW.csv lists OCR-derived reading units and review limitations.
  • Non-PDF audit files are not knowledge documents.
